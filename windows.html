FastNet Connect for Windows

Your PC online
through your iPhone.

FastNet Connect puts a Windows PC on your iPhone's cellular data. The PC joins the iPhone's Wi-Fi network, you scan one code with the free ProxyDeck app, and everything on the PC goes out through the phone.

Download for Windows (x64) What Windows will ask you

Windows 10 or 11. Free for the first 2 hours of connected time, then $29 once. On an ARM PC (Snapdragon), use the ARM64 installer.

Installer blocked or won't start? Use the no-install version (ARM64): unzip it and run FastNetConnect.exe, with no setup to unpack.

Windows will warn you about this download. FastNet is made by one independent developer and is signed with our own certificate, not one bought from a certificate company, so Windows shows it as an unknown publisher. The steps below show each warning and what to click.

What you need.

  • PCWindows 10 or 11, and an account that can approve the administrator prompt. FastNet adds one network adapter, which Windows only lets an administrator do.
  • iPhoneProxyDeck 1.0.6 or later, free on the App Store. Earlier versions cannot scan the pairing code.
  • NetworkThe PC on the same Wi-Fi network as the iPhone. Away from home that is usually the iPhone's own Personal Hotspot network.
  • LicenseNone to start. The 2 hours count only while the PC is connected through the phone. A FastNet license bought for the Mac works on Windows too.

Connect.

  1. Put the PC on the iPhone's network

    On the iPhone, turn on Personal Hotspot. On the PC, join that Wi-Fi network. If both are already on the same home Wi-Fi, that works as well.

  2. Click Connect on the PC

    Open FastNet Connect and click Connect. A pairing code (QR) appears. The app adds its own Windows Firewall rule at this point, so the iPhone can reach it.

  3. Scan the code with ProxyDeck

    On the iPhone, open ProxyDeck. On the Mac Bridge tab, under Pair with a code, tap Scan pairing code and point the camera at the PC. The tab is called Mac Bridge, but it is the one for Windows too.

  4. Keep ProxyDeck on screen

    When the PC shows Connected through your iPhone, everything on it goes out over the phone's cellular data. ProxyDeck has to stay open and in the foreground; the screen stays awake while it is connected.

If the iPhone locks or you switch apps, the PC goes back to its normal network within about ten seconds and reconnects by itself when ProxyDeck is on screen again. No need to scan a second time.

Questions.

Why does Windows say "unknown publisher"?

Windows shows a publisher name only for apps signed with a certificate bought from a certificate company, which costs a few hundred dollars a year. FastNet is signed with a certificate we created ourselves. The signature still proves that every release comes from the same source and was not modified; Windows just cannot attach a verified name to it. The thumbprint above lets you check it yourself.

What does the installer change on my PC?

It copies the app into Program Files, adds a Start menu shortcut, and registers fastnet: links so the Activate button on the license page can open the app. When you click Connect, the app adds one inbound firewall rule for itself and creates a network adapter named FastNet using Wintun, the open-source driver from the WireGuard project. The adapter is removed when you close the app. Uninstalling from Windows Settings removes the app, the link registration and the firewall rule.

My antivirus stopped it. What now?

Some security software blocks any new network driver from an unknown publisher. If FastNet says it could not create its network adapter, allow FastNet Connect in your security software and start it again. A Windows restart that is still pending from an update can cause the same message.

The installer won't start, or says "Unable to execute file in the temporary directory"

That message comes from security software or a workplace policy blocking the installer as it unpacks itself, not from anything wrong with the file. Three things to try, in order: right-click the downloaded FastNetConnect-Setup-x64.exe, choose Properties, tick Unblock at the bottom and click OK; right-click it and choose Run as administrator; or pause your antivirus's real-time protection for a minute, run the installer, then turn it back on. If none of those help, use the no-install version (ARM64): it has no installer at all, so there is nothing to unpack. Unzip it and run FastNetConnect.exe from the folder. If Windows still refuses it, for instance Smart App Control, which has no "run anyway" button, email pjiang726@gmail.com and I'll sort it out with you.

Does the whole PC go through the iPhone?

Yes. While it says Connected, all apps on the PC use the iPhone's connection, not only the browser. When you disconnect or close the app, the PC is back on its own network.

Is the license the same as on the Mac?

Yes. One FastNet license ($29, one-time) unlocks both the Mac and the Windows app. On the page you get after buying, click Activate in FastNet Connect, or copy the key and paste it under Enter license key in the app.

It says Connected but nothing loads. What now?

Click Diagnose at the bottom of the FastNet Connect window. It checks each part of the connection in turn, from this PC to the iPhone to an ordinary web request, and says which one fails and what to do. Copy report puts the details on the clipboard if you want to send them to support.

Does it work with an Android phone?

No. The phone side is ProxyDeck for iPhone.
